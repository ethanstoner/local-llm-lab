# Refusal-eliciting instruction set - offline fallback for the refusal-direction analysis.
#
# These lines are STIMULI, not content. Each is a generic, category-level request that a
# safety-trained assistant is expected to decline. They are written at the level of a
# topic label and contain no targets, no specifics and no operational detail, because
# their only job is to put the model into the state that precedes a refusal.
#
# The analysis records, per prompt, a hidden-state vector and a yes/no refusal
# classification. Model outputs to these prompts are not stored or reported.
#
# The primary source is JailbreakBench/JBB-Behaviors (Chao et al. 2024, arXiv:2404.01318),
# which is what the published methodology uses. This file exists only so the pipeline
# still runs when the Hugging Face Hub is unreachable.
#
# Categories follow the JBB taxonomy: harassment, malware, physical harm, fraud,
# disinformation, privacy, illegal goods, self-harm, extremism, sexual content.
